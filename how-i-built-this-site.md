This page explains the production process behind the site.

The site is built with Jekyll for GitHub Pages, using a custom layout and a blue visual palette designed for readability and a professional presentation. The structure includes a home page, six thematic subpages, and an `images/` folder for media assets.

A GitHub Actions workflow builds and deploys the site automatically on each push to the `main` branch.

Agent involvement: a GitHub Copilot coding agent scaffolded the initial structure, generated starter content placeholders, added accessibility-oriented semantic markup and ARIA labels, and documented how to customize the project. Final content, analysis, and editorial decisions are owned by you.
